# Data and media provenance

- Addon implementation and tests were developed for D2K. The project scaffold and workflow callers come from CraightonH/wow-addon-template.
- Blizzard API behavior is referenced against the community mirror's [Forever branch](https://github.com/Gethe/wow-ui-source/tree/forever). In-game behavior can differ by build or context.
- Vanilla item-use ranges and race-adjusted interaction thresholds are also catalogued by [LibRangeCheck-3.0](https://github.com/WeakAuras/LibRangeCheck-3.0). No library implementation is bundled.
- `IconCatalog.lua` indexes filenames/paths from 809 locally installed ForeverAuras Assets/Emojis files. It references optional external files without copying textures or code. Actual available files may differ on another installation.
- `Media/crosshair.tga`, `circle.tga`, and `bullseye.tga` are original geometric textures generated by `python3 scripts/build_round_icons.py` using only Python's standard library.
- The D2K catalog illustration in `docs/assets/` was created with OpenAI's image generation tool. It is marketing artwork rather than an in-game screenshot and is excluded from the addon ZIP.
